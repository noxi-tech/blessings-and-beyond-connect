# Blessings & Beyond — Connection Hub 🛍️⭐

A clean, mobile-first, 100% hardcoded static single-page website optimized for in-store customers scanning a QR code at checkout.

---

## 🚀 How to Edit Your Links & Information

Everything is directly written in **`index.html`**. No build tools, no configs, no scripts needed.

Simply open `index.html` in your editor and edit the text or links:

- **Google Review Button** (Line 59):
  ```html
  <a class="hero-review-btn" href="[google review link here]" target="_blank" rel="noopener noreferrer">
  ```
- **Instagram Link** (Line 89):
  ```html
  <a href="[instagram link here]" class="action-card" target="_blank" rel="noopener noreferrer">
  ```
- **Website Link** (Line 113):
  ```html
  <a href="[website link here]" class="action-card" target="_blank" rel="noopener noreferrer">
  ```
- **Private Feedback Email** (Line 144):
  ```html
  <a class="safety-net-link" href="mailto:[email link here]">
  ```
- **Logo**: Located at `assets/logo.svg`.

---

## 🖥️ How to Preview

Double-click **`index.html`** in your file explorer to open it immediately in any browser.
